# 拾题离线版

这是可以单独上传到 GitHub Pages 的静态发布目录。
在仓库根目录放置本目录内全部文件（不是只上传 index.html），然后在 Settings → Pages 选择 Deploy from a branch，选择 main / (root)。
首次使用需 HTTPS，安装到桌面后从桌面打开并确认“离线可用”。在“安装与备份”下载约 24 MB 识别包后可断网识别。
手机数据只在浏览器 IndexedDB 中，互不自动同步；通过 JSON 备份迁移。更换域名或仓库路径前务必导出备份。
不要上传数据库、密码配置、用户资料或私人备份。本目录只含应用程序和公开 OCR 组件。
